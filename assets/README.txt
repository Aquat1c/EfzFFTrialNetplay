EFZ FF NETPLAY

Run "EFZ FF Netplay.exe" from this folder. Keep all included EXE and DLL files together.

Set up your controls first, then choose Play Online or Practice. To join or watch a match, enter the host address as host:port. Both players and spectators must use the same release.

Allow the launcher and EFZ through your firewall if prompted. Diagnostic logs are off by default; enable Save diagnostic logs under Settings > Diagnostics only when troubleshooting.
